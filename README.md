# GaN HEMT Simulator PWA

## iPhone 安裝方式
1. 將此資料夾部署到 HTTPS 網站，例如 GitHub Pages、Netlify、Vercel 或公司內部 HTTPS server。
2. 用 iPhone Safari 開啟網址。
3. 點分享按鈕。
4. 選「加入主畫面」。
5. 之後即可像 App 一樣使用。

## 本機測試
可在此資料夾執行：
python -m http.server 8080

然後用瀏覽器開啟：
http://localhost:8080

注意：iPhone PWA 安裝與 service worker 通常需要 HTTPS。
